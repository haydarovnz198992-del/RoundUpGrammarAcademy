ROUND-UP GRAMMAR ACADEMY — ANDROID STUDIO LOYIHASI

Bu APK emas, APK yaratishga tayyor Android Studio loyihasi.

KOMPYUTERDA APK YARATISH:
1) Android Studio o'rnating: https://developer.android.com/studio
2) ZIP faylni oching.
3) Android Studio > Open > RoundUpGrammarAcademy_Android papkasini tanlang.
4) Android Studio Gradle/SDK talab qilsa, Install/Sync ni bosing.
5) Build > Build Bundle(s) / APK(s) > Build APK(s) ni bosing.
6) APK: app/build/outputs/apk/debug/app-debug.apk
7) Shu APK faylini Android telefoningizga o'tkazib o'rnating.
